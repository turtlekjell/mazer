# Sample images

Images in this folder are the reusable sample library shown by Mazer's browser interface.

- Supported formats: PNG, JPG/JPEG, and WebP.
- Add or remove images here, then reload the browser page.
- These files are intended to be tracked in Git.
- Browser uploads do **not** go here; temporary user uploads use `uploads/` and are deleted after generation.

Simple, high-contrast artwork and silhouettes make the most reliable maze shapes.
